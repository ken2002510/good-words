# 給使用者的登入說明（可直接轉貼）

> 用途：Lead 可直接複製以下內容給使用者。
> 依使用者指示：「全權代操，但**登入需要他本人**」。
> 部署者**不會**代填帳密、**不會**繞過任何驗證。

---

## 📋 請你完成兩件事（約 5 分鐘）

作品已經做好、程式碼也已在本機測試全部通過。
現在只剩**最後一步：上傳到網路**，需要你本人的帳號授權。

**為什麼要你親自做？**
GitHub 和 Vercel 的登入授權會綁定你的個人帳號，**只能用你本人的身分完成**，
我無法（也不應該）代替你登入或填寫帳密。其餘所有步驟都由我處理。

---

### 第 1 件事：GitHub（約 2 分鐘）

1. 開啟 https://github.com/new
2. **Repository name** 填：`good-words`
3. 選 **Public**
4. **不要**勾選 Add a README file / .gitignore / license（我們本機已經有了）
5. 按綠色按鈕 **Create repository**
6. 建立好之後，把畫面上方的網址複製給我
   （長得像 `https://github.com/你的帳號/good-words.git`）

> 💡 建議用中性名稱 `good-words`：比賽規定作品不得揭露個人身分，
> 網址會公開，用中性名稱最安全。

---

### 第 2 件事：Vercel（約 3 分鐘）

1. 開啟 https://vercel.com/signup
2. **建議點「Continue with GitHub」**（直接用剛才的 GitHub 帳號登入，最省事）
3. 若要求選擇方案：**請務必選 Hobby（免費）**，不要選 Pro（Pro 要付費）
4. 登入完成後，回來告訴我「Vercel 登入好了」

> ⚠️ 這一步可能會跳出「授權 Vercel 存取你的 GitHub」的視窗 → 按同意即可。
> 之後我 push 程式碼，Vercel 就會自動幫你上架。

---

### 完成後請回報我

只要告訴我這兩句就好：

1. **GitHub 網址**：（貼上你建立好的 repo 網址）
2. **Vercel 登入**：好了

---

### 我會接手做的事

收到你的回報後，我會自動完成：

- 把程式碼上傳到你的 GitHub
- 部署到 Vercel（免費方案）
- 拿到公開網址，並**從外部網路實測**確認能正常使用
- 測試「輸入心事會給好話」與「危機字串會轉介求助電話」
- 把公開網址整理成一張交付清單給你（報名時直接貼上即可）

**預計再 10 分鐘內完成，你不需要再做任何事。**

---

### 常見問題

**Q：會不會要付錢？**
不會。GitHub 公開 repo 免費，Vercel Hobby 方案也免費，全程 $0。

**Q：我的帳號密碼會被你看到嗎？**
不會。你是直接在 GitHub / Vercel 官方網頁上登入，我完全不會接觸到你的帳密。

**Q：需要綁信用卡嗎？**
不用。Hobby 免費方案不需要信用卡。

**Q：上傳的程式碼裡有我的個人資料嗎？**
沒有。我已經做過檢查：程式碼、網站介面都不含姓名、學校、Email 或任何可辨識資訊
（公開的說明文件與切結書檔案也刻意不放上去）。

**Q：比賽期間網站會不會掛掉？**
不會。這個作品的好話回應是**內建在程式裡**的，不依賴任何外部 AI 服務，
所以就算其他網站都掛了，它還是能運作。免費方案在比賽期間（12/01–12/15）足夠使用。
